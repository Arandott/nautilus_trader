# FactorExp Live Trading Strategy 详细说明

## 概述
基于FactorExp表达式的量化交易策略，使用多因子模型进行信号生成和风险管理。

## 数据频率
- **K线频率**: 1分钟K线 (`1-MINUTE-LAST-EXTERNAL`)
- **信号更新**: 每个新的1分钟K线都会触发策略计算
- **订阅数据**: 价格数据(QuoteTick, TradeTick), K线数据(Bar)

## 技术因子详解

### 1. EMA比率 (趋势指标)
```python
表达式: TS_EMA($close, 12) / TS_EMA($close, 26)
用途: 短期趋势相对长期趋势的强度
阈值: 
  - 做多: > 1.005 (短期EMA比长期EMA高0.5%)
  - 做空: < 0.995 (短期EMA比长期EMA低0.5%)
```

### 2. 波动率指标 (过滤条件)
```python
表达式: TS_Std($close, 20) / TS_EMA($close, 20)
用途: 标准化波动率，过滤市场活跃度
阈值: > 0.001 (必须有足够的波动率才交易)
```

### 3. 动量指标 (确认信号)
```python
表达式: ($close - TS_Ref($close, 14)) / TS_Ref($close, 14)
用途: 14期价格变化率
阈值: 
  - 做多确认: > 0.001 (正向动量)
  - 做空确认: < -0.001 (负向动量)
```

### 4. 均值回归指标 (辅助参考)
```python
表达式: ($close - TS_EMA($close, 20)) / TS_Std($close, 20)
用途: Z-Score，价格相对均值的标准偏差倍数
当前版本: 仅用于监控，不直接影响交易决策
```

## 开仓条件

### 做多(LONG)条件
必须**同时**满足以下三个条件：
1. **趋势条件**: EMA比率 > 1.005 (短期强于长期)
2. **动量条件**: 动量 > 0.001 (正向价格变化)  
3. **活跃度条件**: 波动率 > 0.001 (市场有足够活跃度)

### 做空(SHORT)条件  
必须**同时**满足以下三个条件：
1. **趋势条件**: EMA比率 < 0.995 (短期弱于长期)
2. **动量条件**: 动量 < -0.001 (负向价格变化)
3. **活跃度条件**: 波动率 > 0.001 (市场有足够活跃度)

## 平仓条件

### 主动平仓
- **方向转换**: 当信号从LONG变为SHORT或反之时，先平仓再开新仓
- **止损**: 使用动态追踪止损(Trailing Stop)
  - 多头止损: 入场价格 * (1 - 1.5%) = 1.5%止损
  - 空头止损: 入场价格 * (1 + 1.5%) = 1.5%止损

### 风险控制平仓
- **日内交易上限**: 每日最多20笔交易
- **日损失上限**: 每日最大损失$200
- **最大回撤**: 账户回撤超过5%时停止交易
- **余额不足**: 可用余额小于最大可用资金10%时停止交易

## 仓位计算详解

### 资金管理架构
采用多层级资金管理，从保守到激进依次为：

#### 1. 绝对限制层 (用户交易限制)
```python
# ACCOUNT_SIZE_USD=300 表示用户想要用于交易的最大金额
最大可用资金 = ACCOUNT_SIZE_USD  # 直接使用用户设定的交易资金

# 仅当账户余额不足时才调整
if 账户余额 < ACCOUNT_SIZE_USD:
    最大可用资金 = 账户余额 * 80%  # 降级保护
```

#### 2. 账户分级管理
- **小账户 (≤$500)**: 使用60%资金，最保守策略
- **中等账户 ($500-$2000)**: 使用40%资金，适中策略  
- **大账户 (>$2000)**: 使用绝对限制，标准策略

#### 3. 单笔风险计算
使用Nautilus Trader的`FixedRiskSizer`：
```python
参数:
- 入场价格: 当前市场价格
- 止损价格: 入场价格 ± 1.5%
- 风险资金: 有效资金 * 2% 
- 手续费率: 0.04% (taker) 或 0.02% (maker)

计算结果: 确保单笔损失不超过账户净值的2%
```

### 实际仓位示例

#### 200U小账户交易BTC实例:
```
可用资金: $200 * 60% = $120
单笔风险: $120 * 2% = $2.4
BTC价格: $43,000 (假设)
止损幅度: 1.5% = $645

仓位计算: $2.4 / $645 = 0.0037 BTC ≈ 0.004 BTC
名义价值: 0.004 * $43,000 = $172
```

#### 风险验证:
- 最大损失: $2.4 (账户的1.2%)
- 杠杆比例: $172/$120 = 1.43倍
- 安全边际: 充足

## 风险管理机制

### 实时风险监控
1. **账户余额检查**: 每次交易前检查可用余额
2. **仓位限制检查**: 确保不超过最大暴露限制
3. **波动率过滤**: 低波动率时暂停交易
4. **自定义风险监控**: 可选的额外风险监控组件

### 紧急停止机制
- 连续损失达到日限制时自动停止
- 系统异常时自动平仓并停止策略
- 网络连接异常时保护性停止

## 性能预期

### 交易频率
- **信号检查**: 每分钟检查一次
- **实际交易**: 取决于市场条件，预计每日0-5笔交易
- **持仓时间**: 几分钟到几小时，视市场趋势而定

### 风险收益特征
- **目标收益**: 每笔交易盈亏比约2:1 (止盈3% vs 止损1.5%)
- **胜率要求**: 需要>40%胜率来实现盈利
- **最大回撤**: 严格控制在账户净值5%以内

## 适用场景

### 最佳市场环境
- **趋势明确**: EMA比率能够明确区分趋势方向
- **波动适中**: 有足够波动率但不过分剧烈
- **流动性充足**: 确保订单能够及时成交

### 不适合的市场环境  
- **横盘震荡**: 缺乏明确趋势时容易产生假信号
- **极低波动**: 波动率低于阈值时策略暂停
- **极端行情**: 可能触发风险控制机制
